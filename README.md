🚗 Parking Lot Management System in C

A console-based Parking Lot Management System developed using the C programming language. It manages vehicle parking records and uses file handling to store data persistently.

✨ Features

- 🚘 Vehicle entry and registration
- 🚪 Vehicle exit and parking fee calculation
- 🅿️ Parking slot management
- 📋 Display parking records
- 💾 Persistent storage using file handling
- 🔧 Structured data management using C

🛠️ Technologies & Concepts

- Language: C
- File Handling: Storing and retrieving parking records
- Structures: Organizing vehicle information
- Pointers: Managing and accessing data
- Dynamic Memory Allocation: Allocating memory dynamically
- Control Flow: Loops and conditional statements

💾 File Handling

File handling allows parking records to be stored in a file and retrieved when needed, ensuring that data can persist after the program terminates.

Commonly used functions include:

- "fopen()" — Opens or creates a file.
- "fprintf()" — Writes formatted data.
- "fscanf()" — Reads formatted data.
- "fclose()" — Closes an opened file.
